# Contributing

Use a feature branch, keep changes focused, add tests for behavior changes, and ensure the .NET 10, frontend, AI, and data-engineering CI checks pass before opening a pull request.

## Main branch merge policy

- Direct pushes to `main` are prohibited.
- Every pull request targeting `main` requires approval from `@nwr4519678`.
- The pull request author cannot approve their own pull request.
- Required CI checks must pass before merging.
- Administrators should not bypass these requirements except for a documented emergency.
